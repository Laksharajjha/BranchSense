# Security Policy

## Supported versions

BranchSense is currently in alpha. Security fixes are applied to the latest
release and the `main` branch when practical. Older alpha releases may not
receive fixes.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Report it privately
through [GitHub Security Advisories](https://github.com/Laksharajjha/BranchSense/security/advisories/new).

Please include:

- A short description of the vulnerability and its impact.
- Reproduction steps or a minimal proof of concept.
- Affected version, commit, or component.
- Any suggested mitigation.

We will acknowledge reports as soon as practical, keep the report private while
the issue is investigated, and coordinate disclosure with the reporter.

## Scope

This policy covers the BranchSense source repository, published release
artifacts, and official services. Do not include confidential source code or
personal data in a report.
